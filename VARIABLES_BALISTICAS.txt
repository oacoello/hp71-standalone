PARTE 3: CONSTANTES ATMOSFÉRICAS (ISA - STANAG 4355)
================================================================

3.1 PARÁMETROS ESTÁNDAR
----------------------------------------------------------------
Variable        Valor           Unidad       Descripción
-----------     -------         ------       -----------
T0              288.15          K            Temp. nivel del mar
P0              101325          Pa           Presión nivel del mar
L               0.0065          K/m          Gradiente térmico
R               287.05          J/(kg·K)     Constante del gas
g               9.80665         m/s²         Gravedad
gamma           1.4             adim         Cp/Cv del aire

3.2 FÓRMULAS ATMOSFÉRICAS
----------------------------------------------------------------
T(h)   = T0 - L·h                              Temperatura
P(h)   = P0·(T/T0)^(g/(R·L))                  Presión
ρ(h)   = P/(R·T)                               Densidad
a(h)   = √(γ·R·T)                              Vel. del sonido

Donde:
  h = altitud (m), limitada a [0, 11000]m (troposfera)


PARTE 4: FÓRMULAS BALÍSTICAS
================================================================

4.1 FUERZA DE ARRASTRE
----------------------------------------------------------------
Fd = 0.5 · ρ · v² · Cd · A

Donde:
  Fd  = Fuerza de arrastre (N)
  ρ   = Densidad del aire (kg/m³)
  v   = Velocidad del proyectil (m/s)
  Cd  = Coeficiente de arrastre (adim)
  A   = Área de referencia (m²)

4.2 COEFICIENTE DE ARRASTRE (G1)
----------------------------------------------------------------
Cd = cd0 · (G1_Cd(Mach) / G1_CD0_ref)

Donde:
  cd0         = 0.157 (calibrado)
  G1_Cd(Mach) = Interpolación de la tabla G1
  G1_CD0_ref  = 0.2300

4.3 NÚMERO MACH
----------------------------------------------------------------
Mach = v / a(h)

Donde:
  v = Velocidad del proyectil (m/s)
  a = Velocidad del sonido a altitud h (m/s)

4.4 ECUACIONES DE MOVIMIENTO (2D)
----------------------------------------------------------------
dx/dt  = vx
dy/dt  = vy
dvx/dt = -Fd/m · (vx/v)
dvy/dt = -g - Fd/m · (vy/v)

Donde:
  vx, vy = Componentes de velocidad
  m      = Masa del proyectil (43.2 kg)
  g      = Gravedad (9.80665 m/s²)

4.5 INTEGRACIÓN RK4
----------------------------------------------------------------
k1 = f(t, y)
k2 = f(t + dt/2, y + dt/2 · k1)
k3 = f(t + dt/2, y + dt/2 · k2)
k4 = f(t + dt, y + dt · k3)

y(t+dt) = y(t) + dt/6 · (k1 + 2·k2 + 2·k3 + k4)

Donde:
  dt = 0.005 s (paso de integración)

4.6 RESOLUCIÓN QE (MÉTODO BRENT)
----------------------------------------------------------------
Fase 1: Búsqueda de alcance máximo
  - Escaneo de 1° a 59° en pasos de 2°
  - Encuentra ángulo de alcance máximo

Fase 2: Búsqueda binaria
  - Lado ascendente de la curva de alcance
  - 25 iteraciones de precisión
  - Resultado en mils (6400 mils = 360°)


PARTE 5: CORRECCIONES ADICIONALES
================================================================

5.1 DERIVA POR GIRO (SPIN DRIFT)
----------------------------------------------------------------
Fórmula: SD = K · range_km²

Donde:
  K         = 0.015 (constante M107)
  range_km  = Alcance en kilómetros
  SD        = Deriva en mils (hacia la derecha)

Ejemplo:
  10 km → SD = 0.015 · 10² = 1.5 mils derecha

5.2 EFECTO DE CORIOLIS
----------------------------------------------------------------
Fórmula: C = ωe · T · sin(lat) · R

Donde:
  ωe    = 7.2921e-5 rad/s (vel. rotación Tierra)
  T     = Tiempo de vuelo (s)
  lat   = Latitud (-32° Buenos Aires)
  R     = Alcance (m)

Conversión a mils:
  C_mils = C_m · 6400 / range_m
